ReplaceX — программа для автоматической усатновки редуксов для GTA V (RageMP/AltV).  

## Структура проекта
- src/ — исходники программы (.cpp, .h, .ui)
- resources/ — иконки, картинки, заморозка запуска GTA5 и другие ресурсы (манифест для прав администратора)
- installer/ — скрипт установки (.iss)

## Требования для сборки проэкта
- Windows 10/11
- Qt Creator 5 или выше
- Для установки: права администратора (см. манифест в resources/)

## Как использовать
1. Скачайте и распакуйте проект.
2. Откройте ReplaceX.pro в Qt Creator.
3. Соберите проект и запустите.  
4. Следуйте инструкциям установки.
